# ZEB-Construction Managemant

**Building Better Spaces for a Stronger Tomorrow**

A multi-project construction management application for ZEB Construction.

## Main Modules
- Project Management
- Owner Funds & Accounts
- Vendors & Materials
- Contractors & Labour
- Construction Progress
- Floors & Rooms
- Vouchers & Ledgers
- Users & Permissions
- Reports & Analytics

## Technology
- Next.js
- TypeScript
- Supabase
- PostgreSQL
- Vercel

## Status
Project setup in progress.
